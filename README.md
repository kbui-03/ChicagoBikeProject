# ChicagoBikeProject
Our project aims to develop a machine learning model in order to predict the trip duration of Divvy bike trips in Chicago. The original dataset is further enhanced with weather, geographical, and demographical data. The 2 algorithms we chose were Ridge Regression and Random Forest, which delivered R2 scores of 0.17 and 0.25 respectively.
